Returns the lockable resources that match a label, without locking or changing them. The result is a list with one map per resource, with these keys:

  • name
  • labels (list of labels)
  • group
  • description
  • note
  • properties (map of property name to value)

Only resources on this controller are returned; resources of remote servers are not. Set group to return only the resources of that group. A typical use is building the candidates list of the lock step, with the preferred resources first. sort { } does not work in a sandboxed Pipeline, so build the order with findAll: 

def preferred = findLockableResources(label: 'os:Debian && nwcard:1').findAll { r -> !r.description.contains('Test-agent') }
def sorted = preferred.findAll { r -> r.labels.contains('nwcard:2') } + preferred.findAll { r -> !r.labels.contains('nwcard:2') }
lock(candidates: sorted*.name, quantity: 2, variable: 'LOCKED') { echo 'Locked: ' + env.LOCKED }
