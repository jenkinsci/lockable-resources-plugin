Returns the lockable resources that match a label, without locking or changing them. The result is a list with one map per resource, with these keys:

  • name
  • labels (list of labels)
  • description
  • note

Only resources on this controller are returned; resources of remote servers are not. A typical use is building the order list of the lock step: 

def order = findLockableResources(label: 'nwcard:1').findAll { r -> r.labels.contains('nwcard:2') }*.name
lock(label: 'nwcard:1', quantity: 1, order: order) {
    // ...
}
