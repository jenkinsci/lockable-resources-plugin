Disabled by default. When enabled, a lock step fails right away if it requests a positive quantity bigger than the number of matching resources in the selected group, including extra entries. Each extra uses its explicitly selected group or inherits the enclosing step's group. For group-only requests, all members of the selected group are counted. Locked and reserved resources count as existing resources. Such a request could otherwise never be satisfied with the current set of resources. When disabled, the step waits until enough matching resources exist in that group. This is useful when resources appear later, for example cloud nodes that are provisioned after the build starts.
