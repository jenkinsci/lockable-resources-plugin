Number of seconds the resources stay locked after the lock block ends normally or fails, for example when a license server needs a cooldown before it can be used again.

The pipeline continues right away with the steps after the lock block. The resources stay locked in the background and are released when the delay is over; then the next waiting build gets them. The resources page shows the resource as locked until that time. The delay survives a Jenkins restart.

Set to 0 (the default) to release the resources immediately. When the build is aborted, onCancelDelay is used instead. Not supported for remote locks (serverId).
