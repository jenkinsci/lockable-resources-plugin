Optional list of resource names that sets which label candidates are tried first. Listed resources are tried in list order; candidates that are not listed come after them and keep their normal order (sequential, or shuffled for the random strategy).

  • Names that do not match the label, or that are locked or reserved, are skipped.
  • order never adds candidates: it only reorders resources that match the label.
  • A name listed twice counts at its first position.

It applies to label selections (including extra resources) and is ignored for named resources. Use findLockableResources to build the list, for example: 

def order = findLockableResources(label: 'nwcard:1').findAll { r -> r.labels.contains('nwcard:2') }*.name
lock(label: 'nwcard:1', quantity: 1, order: order) {
    // ...
}

Local locks only: order does not apply to remote locks. When the lock goes to a remote server (through serverId or a forced server ID), a warning is written to the build log and order is ignored; the remote server picks resources in its default order.
