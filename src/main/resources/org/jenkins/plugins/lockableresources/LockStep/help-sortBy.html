Optional Groovy expression used to order the resources that match the label. It is evaluated once for each candidate and must return a number. Resources with lower values are locked first; resources with equal values keep the order given by the selection strategy.

The expression can use these variables:

  • resourceName
  • resourceDescription
  • resourceLabels (list of labels)
  • resourceNote
  • resourceLockReason

Example: resourceLabels.contains('nwcard:2') ? 0 : 1 prefers resources that also have the label nwcard:2.

The expression always runs in the Groovy script sandbox. If it fails, is rejected by the sandbox or does not return a number, a warning is written to the build log and the default order is used. It applies to label selections (including extra resources) and is ignored for named resources and remote locks.
