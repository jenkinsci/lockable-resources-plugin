Disables the resource and stores why. A disabled resource is not given to new lock requests, neither by name nor by label. Those requests wait in the queue as if the resource were busy. A build that holds the resource when it gets disabled keeps it until it releases it.

Use disabledCause: null to enable the resource again. Builds waiting for it can then take it.

Example: disabledCause: "Something goes wrong in ${env.BUILD_ID}"
